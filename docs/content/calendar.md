# Field Notes calendar: 10 Nov 2026 – 28 Jan 2027

Two posts a week, Tuesday and Thursday. Keywords and volume estimates are in `keywords.csv`; clusters in `clusters.md`.

**How these go in:** each post is a file `content/blog/YYYY-MM-slug.md` with `month:` set to the publish month and `extra: true` (the calendar engine has one regular slot per month, and Nov/Dec 2026 are already used). Admin → Blog → Editorial calendar imports it as *In review*; Farjad schedules it for the date below. Never publish before the date and never backdate.

**Review column:** *y* = clinical content: keeps the "Awaiting review by an emergency physician" line and needs a physician sign-off before it's promoted as reviewed. *n* = non-clinical (career, process, buying): a paramedic educator or Farjad fact-checks it; the standard last line stays because the README requires it on every post.

**CTA codes:** `demo` = /demo (services, training leads, medical directors). `app` = /download (paramedics and students; switch on once the App Store approves). `services` = /for-services.
